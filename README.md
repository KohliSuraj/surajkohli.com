# surajkohli.com

Personal site. Plain HTML + CSS, no build step. Pushes to `main` deploy via GitHub Pages (`.github/workflows/pages.yml`).

- Edit content in `index.html`, styles in `assets/style.css`.
- Drop resume at `assets/Suraj-Kohli-Resume.pdf`.
- Preview locally: `python3 -m http.server` then open http://localhost:8000
